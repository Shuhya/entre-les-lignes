# Entre les lignes

Jeu narratif en messages (SMS / WhatsApp / fichiers simulés). Une enquête en 6 chapitres, 8 fins possibles — chaque réponse compte.

## 🎮 Jouer

Ouvrez `index.html` — aucune installation, aucun serveur requis.

- Histoire jouable : **« Le Dernier en Ligne »** (l'enquête de Léo)
- Multi-apps simulées : SMS, WhatsApp, Fichiers, Notes d'enquête
- Appels téléphoniques, horloge fiction, indicateur de chapitres
- Décors immersifs par scène (générés par IA)

## 🛠️ Développement

Projet développé avec [Vibe (Mistral AI)](https://mistral.ai) — l'assistant modifie le jeu en direct.

```
index.html                  moteur + histoire (éditable, léger)
assets/avatars.js           avatars des contacts
assets/decors-orig.js       décors d'origine (gare, mer, nuit…)
assets/decors-ia.js         décors IA de l'enquête (champ, voiture, café…)
assets/pluie.js             ambiance sonore pluie
```
